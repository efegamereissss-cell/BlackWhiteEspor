# Black White Esports (BWE) - Valorant Recruitment Portal

Resmi **Black White Esports (BWE)** Valorant takımı oyuncu seçmeleri ve başvuru web sitesi.

## 🚀 Özellikler
- **Apple Estetiği:** Dynamic Island cam menü, Bento-Grid yapısı, akıcı animasyonlar.
- **Resmi Ajan Renders:** Yüksek çözünürlüklü şeffaf Valorant ajan görselleri (Sova, Jett, Omen, Killjoy).
- **Tüm Roller:** Düellocu, Öncü, Kontrol Uzmanı, Gözcü, Flex ve IGL için özel başvuru akışı.
- **Discord Webhook Entegrasyonu:** Başvurular anında BWE yönetim sunucusuna embed formatında iletilir.
- **Güvenlik & Anti-Spam:** Bot honeypot koruması, 60s cooldown rate-limiter ve ping sanitization.

## 🛠️ Kurulum & Dağıtım
- **Vercel:** Doğrudan Vercel ile sıfır konfigürasyonla deploy edilebilir.
- **Yerel Önizleme:** `index.html` dosyasını herhangi bir modern tarayıcı ile açabilirsiniz.
